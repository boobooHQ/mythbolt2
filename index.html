I-02

Path Normalisation

Textbook demonstration · OWASP A01

A long-documented class of web weakness, shown rather than described. A guard allows anything under /public/ by inspecting the raw string, while the router decodes and normalises the path before dispatching. When two components read the same request differently, the decision gets made about one thing and applied to another. Feed them a path and watch it happen.

—

NOTE The guard here is deliberately typical, not strawman: a raw-prefix allowlist is what you find in real middleware. The fix is never a better blocklist — it is deciding on the same normalised value the router will act on.

I-03

Timing Side Channel

Cryptographic hygiene · measured live

A naive string comparison returns the moment it finds a mismatch, so it takes fractionally longer the more characters you get right. That is enough to recover a secret one character at a time. This runs both comparisons on your CPU, now, and plots how long each takes against how much of the secret the guess already matches.

NOTE A browser is a noisy oscilloscope — timers are deliberately coarsened and the JIT interferes. We take the minimum across repeated trials, which is the standard way to suppress scheduler noise. The slope is the finding, not any single value.

I-05

Search Space

Credential strength · honest arithmetic

Strength meters usually reward you for theatre — a capital letter here, a ! there. The only thing that matters is how many guesses an attacker must make. This shows the real arithmetic, and tells you honestly when the arithmetic does not apply.

NOTE This models a randomly generated string over the character classes you used. A human-chosen password of the same shape is worth dramatically less, because real cracking starts with wordlists and mutation rules, not with A…Z. If your candidate is a word with substitutions, treat the number below as an upper bound you will never reach.

I-06

The Oracle

Human layer · Forer effect

The cheapest way past a control is usually to ask someone politely. Give this instrument a name and it will read you accurately — then show you exactly why it was able to.

Drawn from a pool of 0 readings, seeded by the name and today's date — so it is stable all day, which is what makes it feel earned. It fits almost anyone who reads it. You also handed a stranger a professional identity for it. Yours went nowhere. That is usually the only difference.

NOTE Every fragment is written to be true of most people most days. That is the whole technique, and it is the same one behind the message from your CEO that needs a wire transfer before close of business.
