Method

A browser is a noisy oscilloscope: timers are deliberately coarsened and the JIT interferes. We take the minimum across repeated trials, the standard way to suppress scheduler noise. The slope is the finding, never a single value.

I-05

Search Space

Not a strength meter. The actual number of guesses.

Method

This models a randomly generated string over the classes you used. A human-chosen password of the same shape is worth dramatically less, because real cracking starts with wordlists and mutation rules. If your candidate is a word with substitutions, treat this as a ceiling you will never reach.
